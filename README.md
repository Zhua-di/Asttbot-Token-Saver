超节省群聊（astrbot_plugin_super_saver）

给 AstrBot 用的群聊调度插件：让机器人在群里该说才说，把 token 花在真正跟它说话的时候。

这是个主动做减法的插件。它会强行限制机器人的发言频率和发言时机，适合"希望机器人安静、省钱"的场景；如果你希望机器人在群里随时接话、活跃气氛，请不要用这个插件。

介绍：这个插件会限制上下文长度和回复频率，以此达到节省开支的效果，每次唤醒她需要@或者叫她“大肥鱼”“啥鱼”“傻鱼”，唤醒后会开启一个5分钟的会话窗口，在窗口内可以回复，并且每次间隔至少6秒，如果一分钟内回复了5次就会睡着（强制沉默），过两分钟才会苏醒。

作者是区，这个插件是AI生成，大概率不会更新，有bug也懒得修了
